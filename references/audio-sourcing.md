# 配乐与音效：来源、编曲与对位

## 音乐从哪里来（按顺序选）

1. **用户给的曲子**，或用户有授权的曲库：直接用。按它的实际节拍重新对齐画面切点，节拍用 `audio.beatGrid` 记录。
2. **本机确实可用的音乐生成模型**：先确认模型权重真的在本地、运行环境（例如 torch）装好了，再用。只有配置文件的缓存不算"可用"。生成后照样按分镜检查段落，必要时剪辑或叠加冲击、上升音。
3. **代码原创合成**（默认兜底）：为这支片子写一段合成脚本，保留源码和固定随机种子，重新运行能得到同一首曲子。

不要下载一首来路不明的 BGM，不要把参考视频的音乐扒下来用，也不要把上一支片子的曲子改个名字就当作新配乐。用户要求静音时遵从，并记录 `audioExceptionReason`。

## 代码原创：先编曲，再合成

**编曲从分镜来**：打开 `DIRECTION.md` 的镜头表，逐段写出音乐要做什么，时间直接取 `plan.json` 的镜头边界：

- 开场是渐强、悬念，还是直接进节奏？
- 商品登场、章节切换、片尾落版要不要冲击点？冲击前留不留一瞬空白？
- 读文字、看标注的段落要让出空间：乐器变少，旋律退后。
- 快切段落加密节奏或上升音，结尾有完整的和声收束，并按片长留出尾音。

**风格从商品气质和目标顾客来**：[影片方向](direction.md) 里的"声音"轴先定下类型，再选配器，而不是每次都做同一种音乐：

| 音乐风格 | 适合的商品/顾客 | 配器与手法 |
|---|---|---|
| 极限运动 | 越野、运动装备、护具、户外硬件 | 失真吉他、有冲击力的鼓、冲击音和上升音；140–175 BPM；build–drop 结构，drop 对准影片的关键时刻 |
| 日式"酷哥"街头 | 改装、复古、街头潮流、通勤配件 | Rhodes 电钢琴、slap/无品贝斯、爵士和弦（maj7/9/13）、摇摆的 lo-fi 鼓、黑胶底噪，点缀尺八/筝 |
| 湾区技术宅 | 电子类配件（导航、通讯、充电）| 模块合成器琶音、glitch 打击乐、极简钢琴、乐观的大调、渐变的音序；Four Tet / IDM 感 |
| 高端、技术 | 精密加工件、碳纤维、高价位改装件 | 稀疏钢琴、次低频、颗粒质感、细弦乐、精确的点击声；克制、留白、干净的低频 |
| 温暖、人文 | 旅行、露营、家居、个护、新手向商品 | 指弹木吉他、毛毡钢琴、大提琴、鼓刷、环境录音；松弛的节奏、自然的房间声、简单旋律 |
| Deep house | 都市夜生活、时尚服饰、彩妆 | 118–124 BPM、四拍底鼓、反拍踩镲、爵士七/九和弦、温暖的次低频、人声切片、侧链与滤波扫频 |
| 后朋克 | 硬派、复古、黑色系商品 | 浸在合唱/延迟效果里的棱角吉他、旋律性的推进贝斯、干的通鼓为主的鼓组、极简和弦 |
| Techno | 夜间、灯具、反光类商品 | 125–140 BPM、909 底鼓带隆隆低音、多层打击乐、缓慢变化的滤波自动化、dub 和弦 stab、16–32 小节编排 |
| 轻快、友好 | 价格亲民的小配件、清洁保养用品 | 明亮的键盘和弦、短音旋律、轻拍手、马林巴类音色 |
| 安静、专注 | 做工细节巡礼 | 氛围铺底、稀疏的铃音、几乎没有鼓 |

代码合成无法真实还原失真吉他、人声这类音色时，要么换一个合成擅长的风格，要么请用户提供曲子；不要用一个听感廉价的模拟版硬上。

**合成的要点**：

- 按总线（鼓、低音、铺底、旋律、效果）分别合成，最后混合。各自的包络、声像和音量要能单独调。
- 所有时间都用拍和小节换算。改片长或速度时，所有段落时间一起改，并检查尾音越界。
- 简单的键盘/铃音风格只需 Python 标准库 + FFmpeg；需要 supersaw、滤波扫频、卷积混响、侧链时用 numpy/scipy/soundfile，装在工程自己的 venv 里。
- 不要把画面动作的扣合、点击、提示音写进配乐，那些是独立音效，后面要单独对位、单独让位。
- 导出后看频谱图和每秒响度（见 [审片](review.md)），确认段落结构和低频量。低频过重是合成配乐最常见的问题。

## 音效：先找录音素材，缺项再生成

实物商品的音效最好是**真的声音**：搭扣扣合、拉链、魔术贴撕开、金属件拧紧、接口插入、磁吸吸附、泵头按压、盖子合上、雨声。各品类常用的录音方向见品类笔记。合成音只用来补转场和强调这类抽象角色。

1. **用户已有、来源清楚的素材**：包括用户自己录的商品操作声（最贴合，优先）。
2. **本机已装的录音素材库**：许可说明读它自带的 credits/license 文件，并记录进工程。
3. **素材站搜索**：例如 [Pixabay 音效库](https://pixabay.com/sound-effects/)。下载链接必须来自真实的下载操作，不要编造 CDN 地址。素材站需要交互式下载、当前工具拿不到文件时，如实记录，改用下一项。
4. **代码生成**：`python3 <skill-dir>/scripts/make_sfx.py --output assets/sfx-gen` 生成 click、pop、toggle、typing、ding-dong、success、error、resolve、whoosh、sweep、impact 共 12 个原创 WAV（含 click-alt）。适合转场（whoosh/sweep）、商品落定（impact/pop）、标注出现（click）、收尾（resolve）；不适合冒充拉链、金属这类具体材质声。

可辨认的特定声音（某款车的引擎声、某个品牌设备的提示音）可能来自别人的录音作品或商标，按素材许可使用；与商品无关时不要为了"氛围"硬加。

## 对位：让声音落在动作上

用 `scripts/sfx_landmarks.py` 实测每个文件的起音点、峰值时间和峰值电平：

```sh
python3 <skill-dir>/scripts/sfx_landmarks.py assets/sfx/*
```

- 扣合、点击、弹出：用**起音点**对齐画面动作。
- whoosh、冲击、上升音：用**峰值**对齐切点或撞击帧，声音要比画面先开始。
- 写入 plan：`syncOffset` = 所用的落点，`at` = 动作时间 − `syncOffset`。
- 增益：让音效在出现那一刻的峰值不低于压低后的配乐峰值。录音素材接近 0 dBFS，生成音效约 −20 dBFS，同样的 gain 听感差很多。

## 留下来源

`evidence/audio-selection.json` 记录：

- `music`：来源（用户提供 / 生成模型 + 模型名 / `code-original` + 脚本路径）、时长、BPM、调性、段落时间。
- `sfx[]`：每个文件的作用、来源（库名、详情页或作者、用户自录）、许可、本地路径。回退到生成音效时写明实际原因，例如"素材站需要交互式下载，当前工具无法获取文件"。未知就写未知，不要编造搜索经历。

下载素材用于成片，和把原录音打包成可再分发的素材库是两回事。这个 skill 不捆绑第三方录音；工程里用到的素材按其现行许可使用。

最后按 [混音与成片检查](audio-and-qa.md) 混音。
