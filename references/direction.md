# 影片方向：先定方向，再写代码

决定一支片子好不好看的，是写代码之前的设计：它讲什么、看起来是什么气质、每个镜头的主角是谁、字多大、商品占画面多少。把这些写进 `DIRECTION.md`（初始化时已生成问题模板）再动手。

只按清单和指标做出来的片子，节拍对得再准，画面也会挤、字小、像幻灯片；先写画面规范和镜头表，同样的素材观感完全不同（见 [案例复盘](case-study.md)）。

## 1. 拆参考（用户给了参考视频/图片时）

1. 抽帧看全片：`ffmpeg -i ref.mp4 -vf "fps=1,scale=400:-1,tile=6x8" -frames:v 1 sheet.png`，再对关键时刻截全尺寸帧。
2. 逐个列出手法：它是什么、在表达什么（坚固？轻便？速度感？安心感？）、出现在哪一段、持续多久。
3. 学"做法"，不抄"样子"：参考片的颜色、图形、字体、音乐属于它的品牌。写清楚本片是否采用、改写成什么，以及改写的依据。

## 2. 提炼商品气质

从事实表、照片和用户输入回答，不要凭印象：

- **谁在用、在什么情境下用、用起来是什么感觉**：通勤族的实用、出差党的利落、户外玩家的硬派、护肤爱好者的仪式感、新手的安心……各品类常见的顾客与场景见品类笔记。
- **顾客痛点**：买它之前遇到什么麻烦（雨天行李湿、出差要带一堆充电器、桌面线材乱、乳液涂完发黏）。痛点必须真实存在于目标顾客身上，不为了叙事编造。
- **外观与材质**：主色、表面处理、材质、形状语言。来源写到照片文件名。
- **品牌设计语言**：品牌色、字体、Logo（见 [商品与品牌审计](product-and-brand.md)）。
- **母题候选**：能直接变成画面的商品元素。
  - 外形轮廓与结构（扣具、拉链、关节、反光条、切削面）
  - 材质与工艺（缝线、织纹、刻印、阳极氧化的颜色）
  - 使用动作（装上、卡住、拉紧、展开、折叠）
  - 使用位置与周边物件的关系（装在车上、放在桌面、收进包里、涂在脸上）
  - 使用场景与环境（雨、夜、通勤、出差、户外、浴室）
  - 品牌名/商品名的字面意象

## 3. 提出三个方向，沿不同的轴拉开

每个方向在下表每个轴上各选一个，彼此要**至少在三个轴上不同**，而且各自内部要自洽。选项只是举例，可以自己加：

| 轴 | 可选取向（举例） |
|---|---|
| 底色与光 | 黑色摄影棚 + 轮廓光；水泥灰工业风；品牌色大色块；户外自然光照片感；夜间灯光与反光；明亮柔光的浴室 / 梳妆台 |
| 字体声音 | 超细大字；粗重冲击；等宽工程感（规格书风）；圆润亲和 |
| 母题来源 | 商品结构；材质工艺与质地；使用动作；使用场景；品牌标志 |
| 镜头语言 | 平面排版编辑；摄影棚浮空 + 视差；微距特写；蓝图/工程图；实装场景推近 |
| 转场词汇 | 硬切卡拍；推近接续；遮罩擦除（形状取自商品轮廓）；匹配剪辑（前一镜的形状变成后一镜的商品）|
| 节奏 | 发布会式从容；预告片式紧凑；轻快俏皮；安静叙事 |
| 声音 | 失真吉他与鼓（极限运动感）；Rhodes 与爵士和弦（日式街头感）；钢琴与弦；氛围铺底；用户提供的曲子 |

然后按商品气质、目标顾客和发布渠道选一个，写下理由。用户想先看方向时，把三个方向和 3–6 张关键静帧给用户选，否则直接继续。

## 4. 本片专属手法（3–5 个）

每个手法都必须能写成"因为商品有 X，所以用 Y"。写不出 X 的手法，删掉。

一些推导的例子（只说明推导方式，不是菜单）：

| 商品有什么 | 可以长成什么 |
|---|---|
| 止水拉链、防水面料（有测试依据） | 水珠沿面料滑落的粒子层，拉链拉合的瞬间配清脆音效 |
| 手机支架的防振结构 | 背景画面振动、手机保持静止，标注线指向减振部件 |
| 充电器的折叠插脚 | 插脚收起的一瞬间切到口袋特写，配机械"咔嗒"声 |
| 啫喱质地、回弹 | 微距下手指按压后回弹，配一个轻柔的"啵"声 |
| 铝合金切削件、阳极氧化 | 黑色摄影棚，一条高光沿切削面扫过 |
| 工具不用即可安装 | 安装步骤编号 1→2→3，每步一个"咔"声，计时器只在有依据时出现 |
| 多色 / 多色号可选（都有实拍） | 同一机位硬切换色，节拍对重拍 |
| 品牌 Logo 的几何形 | Logo 的形状做遮罩转场 |

各品类笔记里还有更贴合该品类的推导示例。

[视觉手法词汇](visual-vocabulary.md) 列了更多手法及其实现要点。

## 5. 反重复

- **跨片**：动手前看看同一工作区里之前用本 skill 做的片子（相邻目录下的 `DIRECTION.md`、`evidence/contact-sheet.png`）以及 [案例复盘](case-study.md)，列出它们的开场、章节处理、背景手法和配乐。新片至少在三个轴上与最近一支不同，并且不原样复用它的开场手法、章节手法和背景效果。同一品牌的系列片可以共享品牌片头/片尾，但中间的手法要从各自商品推导。
- **片内**：不要所有元素都用同一种入场；相邻镜头换取景（全景 ↔ 特写 ↔ 大字）或换明暗；同一种转场不连用三次以上。
- **案例不是模板**：案例里的手法属于那件商品和那一次推导，另一件商品直接照搬，就是千篇一律。

## 6. 叙事结构，按内容选

默认的"钩子 → 商品登场 → 卖点证明 ×3–5 → 细节快切 → 落版"只是其中一种。也可以：

- 痛点 → 转折 → 解决（适合解决明确烦恼的商品：防雨、防掉落、线材收纳）
- 安装 / 使用三步走（适合"上手简单"是主要卖点的商品）
- 一天 / 一次出行（出发 → 路上 → 到达，适合收纳、充电、通讯类）
- 使用前后（只和自己的未使用状态比，机位和光线一致）
- 细节 / 质地巡礼（适合做工、材质、质地是卖点的商品）
- 内容物开箱（适合套装、配件多的商品）

品类笔记列了各品类常用的结构及其注意事项。

## 7. 画面规范（frame design system）

从商品推导，写成具体数字：

- 画幅、帧率、底色、安全区（重要内容避开四边各 5%，底部再多留约 8%，Amazon 播放器控件会盖住底部）。
- 字号阶梯：主标题、次标题、说明、标注，每种语言分别给字号和字重（CJK 通常要比拉丁字母大一级才同样易读）；字体来自品牌或有授权的字体，每种语言分别指定。画面文字 ≥ 28px（1080p），标注里的数字 ≥ 32px。**最长的语言版本放得下才算定稿。**
- 商品上镜：建立镜头商品占画面高度 50–70%；特写的放大倍数不超过照片分辨率允许的上限（见 [素材处理](asset-pipeline.md)）。
- 动效语法：入场方式、缓动族、时长范围，以及本片**不用**什么（例如"不用回弹""不用彩虹色""不做超过 8° 的倾斜"）。

## 8. 镜头表

每个镜头写：时间、主角（只有一个）、画面与动作（带子拍时间）、上屏文案、声音。一个镜头里至少有一次状态变化或镜头运动；超过 2.5 秒完全不动，只能是在给观众读字。镜头长度有长有短：开场、快切短，卖点证明长。

写完镜头表再开始搭镜头。每搭完一个镜头就出静帧，和镜头表对照（见 [审片](review.md)）。
