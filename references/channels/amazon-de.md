## 法规要点

- **UWG（反不正当竞争法）**：误导性说法、无依据的最上级（„der Beste“„einzigartig“）都有被警告的风险。
- **Werbung mit Selbstverständlichkeiten**：把法定要求当成特别优点宣传是误导。例如把 CE 标志、"含 2 年法定保修"、化妆品的"无动物实验"（欧盟法定）当卖点。可以出现在规格画面，不做主打。
- **Testsieger / TÜV / Stiftung Warentest**：只有真实获奖、获得测试机构授权使用标志时才可以出现，并标注测试期号；TÜV 等证明要有证书编号。
- **环保说法**：欧盟指令 2024/825 由各国转化为本国法，自 **2026-09-27** 起适用，禁止没有公认卓越环保表现依据的笼统环保说法（„umweltfreundlich“„nachhaltig“„klimaneutral“），也禁止靠碳抵消宣称"气候中和"，以及没有认证体系支撑的自创可持续标签。要说就说具体、可核对的事实（„Gehäuse aus 50 % recyceltem Kunststoff“）。
- **品类法规**：化妆品功效宣称按欧盟 655/2013 标准，健康相关说法另受 HWG（医药广告法）限制；电子产品 CE / RoHS / WEEE；摩托车部件 ABE / StVZO / E-mark。详见各品类笔记。
- **语言**：面向德国顾客的版本用德语说明；英文点缀可以保留，但不能是理解商品的唯一信息。
