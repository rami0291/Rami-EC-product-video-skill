## 法规要点

- **CAP Code / ASA**：广告必须有证据支持客观说法，不得误导；ASA 处理过美妆广告用滤镜夸大效果的案例，前后对比画面不要修图。
- **DMCC Act 2024**：2025 年 4 月起 CMA 可以直接对违反消费者保护法的行为处以罚款，误导性说法的风险比以前高。
- **环保说法**：CMA Green Claims Code 要求环保说法真实、清楚、不遗漏重要信息、比较公平、覆盖全生命周期、有证据。"eco-friendly""sustainable"这类笼统说法要么具体化（"made with 60% recycled polyester"），要么不用。
- **品类法规**：UKCA / CE 标志（不要当成卖点宣传）、化妆品按英国化妆品法规（UK Cosmetics Regulation），功效宣称标准与欧盟相同。
- **价格与促销**、评价排名、外部引导同 [Amazon 通用](amazon-common.md)。
