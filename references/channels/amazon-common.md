# Amazon 商品视频：各站点通用

Amazon 的视频规则会更新。下面是制作时的起点和常见拒审点，**每次上传前以当地 Seller Central 当时的视频上传说明和商品详情页规则为准**；与这里不一致时以官方为准，并把这一页改掉。各站点的差异在 [amazon-jp](amazon-jp.md)、[amazon-us](amazon-us.md)、[amazon-uk](amazon-uk.md)、[amazon-de](amazon-de.md)、[amazon-fr](amazon-fr.md)。本页不是法律意见。

## 规格起点

| 项目 | 起点 | 说明 |
| --- | --- | --- |
| 画幅 | 16:9，1920×1080 | 详情页播放器以横版为主；竖版另做，不直接裁 |
| 帧率 | 30 fps | |
| 格式 | MP4（H.264 + AAC） | `render.mjs` 默认输出 |
| 时长 | 30–60 秒 | 详情页上很多人看几秒就走：前 3 秒内出现商品本体 |
| 声音 | 有配乐和音效 | 但信息必须靠画面和文字就能看懂：不少人静音观看 |
| 片尾 | 品牌 Logo + 商品名 | 不放网址、QR 码、"立即购买"类按钮样式 |
| 安全区 | 四边各 5%，底部再多留约 8% | 播放器控件会盖住底部 |

同一支片子的多个语言版本共用时间线和画面，各自上传到对应站点；每个版本都要单独过一遍下面的检查。

## 各站点都不要出现

| 类别 | 例子 | 改法 |
| --- | --- | --- |
| 价格与促销 | 价格、Sale、% OFF、包邮 / Free shipping、限时、优惠券 | 删掉；价格和活动会变，视频不会 |
| 评价与排名 | ★4.5、"顾客好评"、Best Seller、No.1、Amazon's Choice | 删掉；改为说明商品本身的事实 |
| 竞品与比较 | "比 X 牌强 2 倍"、出现别家商品或商标 | 只和自己的旧款 / 未使用状态比，且要有依据 |
| 外部引导 | URL、QR 码、SNS 账号、电话、邮箱、"去官网" | 删掉；照片里吊牌、包装上的网址也要遮挡 |
| 保证与承诺 | 退款保证、终身保修、"永远不会坏" | 删掉；保修条款写在商品页，不进视频 |
| 时效信息 | "新品""2026 最新款" | 只在事实长期成立时用；"最新"会过期 |

`check_delivery.py` 按每个版本的语言和站点，用 `scripts/data/claims.json` 里的关键词提示这些类别。关键词匹配有误报也有漏报（例如 "ON/OFF" 的 OFF、"best" 出现在无关语境），每一条都要人工读上下文。

## 慎用（需要依据）

- **最上级与绝对说法**：最强、最好、完美、世界首款、100%。没有客观依据就改成具体事实。
- **性能与认证**：防水 / IP 等级、耐荷重、认证（各品类笔记列了常见项）。只有事实表里有测试报告 / 认证 / 规格书原文才上屏，用词与原文一致。
- **环保说法**：环保、可持续、碳中和、可降解。欧盟从 2026-09-27 起禁止没有公认依据的笼统环保说法（见德法站笔记），其他站点同样需要具体依据。
- **合成场景**：使用场景是合成或模拟的，加对应语言的说明（见各语言笔记），并确保不暗示未被证明的性能。
- **安全相关**：护具、灯具、电池、儿童用品，不做"安全保障"类承诺。

## 交付前检查

1. 每个版本的 `check_delivery.py` 措辞提示逐条看过。
2. 遮住画面只看文字：每个版本的每一句都能在事实表里找到出处；各版本的数字一致。
3. 逐帧检查每个版本的最终 MP4 关键帧：没有第三方 Logo、个人信息、网址，遮挡在缩放移动中没有漏出。
4. 静音看一遍：不开声音也能看懂是什么商品、怎么用。
5. 交付时写明：哪些规则是按本页和站点笔记检查的、哪些需要用户在 Seller Central 上传时再确认。
