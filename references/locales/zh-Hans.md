# 简体中文（`zh-Hans`）

默认版本：`zh-Hans` → `other`。Amazon 目前没有以简体中文为主语言的站点，中文版通常用于内部审片、给国内团队确认，或投放到其他平台；标题默认带英文点缀（`accent: en`）。语言无关的写法见 [分镜与文案](../story-and-copy.md)。

## 文案写法

- 说明交代对象 + 动作 + 结果，不写四字口号堆砌：
  - ✗ "风雨无阻，随心出发。" → ✓ "止水拉链和防水面料，下雨时包里的东西也不容易湿。"
  - ✗ "快充黑科技。" → ✓ "单口最高 65W，能给支持 USB-C 充电的笔记本供电。"
  - ✗ "肌肤焕新。" → ✓ "质地清爽不黏，涂完很快吸收。"
- 用顾客熟悉的叫法，部件名、成分名与规格书一致；不用"黑科技""天花板""颠覆""极致体验"这类无法证明的词。
- 数字、单位与规格书原文一致，中文与数字 / 英文之间是否加空格，全片统一。

## 排版

- 中文标题和说明统一无衬线（黑体），用字重区分层级（`typography.cjkStyle: "sans-serif"`）。
- 中文与英文点缀分别 span（`lang="zh-Hans"` / `lang="en"`），在 `typography.fonts` 分别指定（Noto Sans SC、思源黑体可作开源起点）。
- 行首禁则：逗号、句号、顿号、右括号、右引号不放行首（CSS `line-break: strict`）；最后一个字单独成行时改短或调列宽。
- 中文和日文共用汉字但字形不同：不要让日文字体渲染中文（会出现日式字形），反之亦然。

## 阅读速度

按约 **6 字 / 秒**（去掉空白）提示，只是人工阅读的起点。

## 本地化注意

- 合成场景标"图片仅供参考"。
- **如果中文版要在中国大陆投放**：《广告法》禁止"国家级、最高级、最佳"等用语，非医疗商品不能涉及疾病治疗，化妆品功效宣称需要评价依据（特殊化妆品需注册）。本 skill 目前没有大陆平台的渠道规则，投放前请按平台规范另行审查。
