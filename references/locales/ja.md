# 日本語（`ja`）

默认版本：`ja-jp` → Amazon.co.jp，标题默认带英文点缀（`accent: en`）。语言无关的写法见 [分镜与文案](../story-and-copy.md)，市场规则见 [Amazon.co.jp](../channels/amazon-jp.md)。

## 文案要说人话

- 标题可以短，说明不能只剩关键词。说明尽量交代对象 / 动作 / 结果，第一次看到的人也知道这件商品能做什么。
- 用目标顾客熟悉的词，不用内部型号代码和工厂术语。骑手用シート、タンク、ハンドル、キャリア、ツーリング；电子产品用充電器、ケーブル、急速充電、ポート；美妆用化粧水、美容液、うるおい、ハリ。
- 部件名、材质名、成分名与规格书一致；不改成「もっと快適」「ストレスフリー」「ワンランク上」这类无法证明的泛词。
- 数字带单位，与规格书原文一致：「約1.2kg」不要写成「1kg」。

| 过于省略 | 更清楚（前提是事实表里真有这些事实） |
|---|---|
| 雨でも、安心。 | 止水ファスナーと防水生地で、雨の日も荷物が濡れにくい。 |
| 取付、カンタン。 | 付属のベルトをシートに回して締めるだけ。工具は要りません。 |
| 充電、爆速。 | USB-Cポートは最大65W。対応ノートPCもこれ1台で充電できます。 |
| しっとり、続く。 | 塗った後もべたつかず、朝のうるおいが夕方まで続く使用感。 |

| 不通过 | 为什么不清楚 | 可以这样说（以真实事实为前提） |
|---|---|---|
| ツーリングが、もっと自由に。 | 没说商品做了什么 | 荷物をシートに固定できるので、両手が空いたまま走れる。 |
| 最強の耐久性。 | 绝对说法，没有依据和对象 | 1680Dポリエステル生地を使い、擦れや引っかきに強い。 |
| 肌が生まれ変わる。 | 药效暗示（薬機法） | 角質層までうるおいを届け、キメを整える。 |

这些句子只说明写法，不能直接套到没有这些功能的商品上。美妆的可用措辞受 薬機法 约束，见 [美妆 / 个护](../categories/beauty.md)。

## 标题的英日分工

默认英文短标题 + 日文清楚的一句话，两者都在主要视觉层级：英文负责提炼卖点 / 动作，日文负责让人直接理解。

- 日文标题和说明统一无衬线体系（ゴシック），用字重 / 字号区分层级；不要明朝体和ゴシック混排（`typography.cjkStyle: "sans-serif"`）。
- 英文独立 span（`lang="en"`）、日文独立 span（`lang="ja"`），在 `typography.fonts` 分别指定。**不是让 fallback 随机分配字形。**
- 英文必须贴合卖点，不机械翻译日文长句，也不为了排版硬塞无关口号。日文说明即使观众不懂英文也能独立理解。
- 字体来自品牌或有授权的字体（Noto Sans JP、源ノ角ゴシック 等开源字体可作起点）。正式工程把字体文件放进 `assets/fonts/` 并查看实际字形，不能仅凭 CSS 字体名判断已加载。

| 英文点缀（`accent`） | 日文标题（`headline`） | 日文说明（`description`） |
|---|---|---|
| Rain-ready | 雨の日も、中身は濡れにくい | 止水ファスナーと防水生地で、急な雨でも荷物を守ります。 |
| No tools | 工具なしで、すぐ付く | 付属ベルトをシートに回して締めるだけで固定できます。 |
| Folds flat | プラグを折りたためる | プラグが本体に収まり、ポケットに入れやすい。 |

## 排版与断行

- 行首禁则：句読点（、。）、長音（ー）、小书き假名（ゃゅょっ）、閉じ括弧不放行首。CSS 设 `line-break: strict`；需要按词换行时用 `word-break: keep-all` 加手动断行点（`<wbr>`），不要靠 `white-space: nowrap` 让文字溢出。
- 说明里最后一个字或标点单独掉到下一行时，改短一两个字或微调列宽。
- 数字与单位用半角（65W、30L），全角括号与半角数字混排时检查间距。

## 阅读速度

`check_delivery.py` 按约 **6 字 / 秒**（去掉空白）提示，起点是 5–6 字 / 秒。画面同时有复杂变化时要留更多余量；这是人工阅读的起点，不是通过阈值。

## 本地化注意

- 合成或模拟的使用场景，画面角落加「※画像はイメージです」。
- 从其他语言版本改写时，不要逐句翻译：日文说明通常更需要交代"装在哪、怎么用"，英文版可以更短。
- 2023 年 10 月起，日本的 ステマ規制（景品表示法）要求带广告性质的体验谈、达人内容标明是广告；商品视频里不要放伪装成普通用户的评价。
