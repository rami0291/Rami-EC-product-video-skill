# 审片：边做边看，最后看成片

自动检查只能证明结构和文件是对的。好不好看要看画面，这一页讲怎么高效地看，以及实际做片时反复出现的问题。

## 三个节点

1. **每搭完一个镜头**：`node stills.mjs evidence/stills <这个镜头内 3–4 个时刻>`，拿静帧和 `DIRECTION.md` 的镜头表对照：主角是不是一眼能看出来？商品清不清楚？字号够不够？有没有撞在一起？`stills.mjs` 打印的页面错误和加载失败的图片在这里就能发现。
2. **全片第一次导出后**：
   - 2 fps 联系表看节奏和构图：`ffmpeg -i final.mp4 -vf "fps=2,scale=384:-1,tile=6x9" -frames:v 1 sheet.png`（前后两半各一张）。
   - 10 fps 条带看每个转场：`ffmpeg -ss <切点前0.4秒> -t 1 -i final.mp4 -vf "fps=10,scale=320:-1,tile=10x1" -frames:v 1 cut.png`。
   - 特写、微距、标注镜头截全尺寸帧，确认商品边缘清晰、文字和数字可读。
   - 把全尺寸帧缩到手机宽度（约 400px）再看一次：Amazon 上很多人用手机看。
3. **修改之后**：只重看改过的镜头和它前后的转场，最后再整体过一遍。

多语言片子：第 1 步先用最长的语言版本（通常是德语）出静帧，版式定稿后再给每个版本各出一组；第 2 步每个版本的 MP4 都出联系表，重点看文字有没有溢出、断行和缺字。画面和声音共用，转场条带看一个版本即可。

## 常见问题

| 看到的现象 | 通常的原因 | 改法 |
|---|---|---|
| 标题和商品撞在一起、字挤在角落 | 没有字号阶梯和安全区，或者标题列太窄 | 回到画面规范，给标题列固定宽度和字号；缩短文案，不要缩字号 |
| 说明最后一个字、标点或单词单独掉到下一行 | 文字宽度刚好超出一点；语言的断行规则没生效 | 改短或微调列宽；确认设了 `lang`，按语言笔记处理（CJK 行首禁则、德语断词、法语标点前不换行空格）；不要靠 `nowrap` 让文字溢出 |
| 某个语言版本的文字挤出版面 | 版式按短语言定稿，长语言（德、法）放不下 | 按最长的语言重定标题列宽和字号阶梯，所有版本一起重出静帧 |
| 某个语言版本出现豆腐块或奇怪字形 | 字体缺字形，fallback 换成了别的字体（例如日文字体渲染中文） | 在 `typography.fonts` 给该语言指定覆盖完整的字体，静帧里逐字检查 |
| 商品边缘发软、细节糊 | 推近超过照片分辨率上限 | 降低终点放大倍数，或换高分辨率原图；不要用 AI 放大补细节 |
| 深色背景上商品有白边 | 抠图时带进了白底的抗锯齿边 | 收缩选区 1–2px 重新羽化，或在深色背景上重抠 |
| 商品像纸片 | 倾斜角度太大、视差幅度太大、没有投影 | 倾斜 ≤ 8°，视差 2–5%，加贴地投影 |
| 商品看起来浮在场景外 | 场景合成时光线方向、色温、投影不一致 | 统一色温，按场景光源方向加投影；对不上就换成摄影棚镜头 |
| 标注线指歪了 | 锚点用屏幕坐标写死，照片缩放后错位 | 锚点改用照片归一化坐标，由 `onRender` 换算 |
| 场景镜头里露出第三方 Logo / 车牌 / 屏幕个人信息 | 遮挡层没跟随推近移动，或某一帧漏了 | 遮挡挂在照片层内部一起变换；逐帧条带检查整个镜头 |
| 颜色和实物不一样 | 调色过度、品牌色背景反射到商品上 | 商品层不做整体调色，只修白平衡；和原图并排对比 |
| 浅色切到深色时中间一片灰 | 长交叉淡化 | 硬切，或者前一镜的主角先模糊退场再切 |
| 某一段 3 秒以上完全不动 | 最后一个动作之后没有后续 | 加一次缓慢推近或下一个标注出现，或者缩短镜头 |
| 所有元素用同一种入场 | 只用了一个 reveal | 主角、辅助信息、背景分别设计出场；相邻镜头换一种 |
| 每支片子看起来都一样 | 直接复用案例或上一支的手法 | 回到 `DIRECTION.md` 第 3–5 节，重新从商品推导 |
| 背景效果抢了商品 | 气氛层对比太高，或者铺在商品后面太花 | 卖点镜头背景保持安静；效果留给字卡、品牌和转场 |

## 指标只是提示

`check_delivery.py --video` 会报告静止帧比例、最长静止段和硬切次数（`pacing`）。它们用来提醒"去看看某一段"：阅读停顿是必要的，大面积深色背景上的小动作也会被算成"静止"。**不要为了让数字好看去加没意义的晃动，也不要把数字达标当成片子好看。**

## 声音

- 能试听就逐段听：单独听 `sfx-stem.wav`，再听 master，最后听编码后的 MP4。
- 不能试听时如实说明，并用可以看到的证据检查结构：频谱图（`ffmpeg -i music.wav -lavfi showspectrumpic=s=1600x500:scale=log:fscale=log music-spec.png`）和每秒响度，确认冲击点、停顿、渐强和收尾落在该在的时间。低频是否过重，在频谱图上很明显。
