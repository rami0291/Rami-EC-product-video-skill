# 品类笔记：美妆 / 个护

适用于：护肤品、彩妆、洗护发、身体护理、香氛、美妆工具（刷具、海绵）、个护小家电（另读 [3C 电子](electronics.md)）。

这是功效说法管得最严的品类。各市场都有一条核心线：**化妆品只能说"清洁、美化、保持状态"，不能说"治疗、改变身体结构"**，越线就变成药品或医疗器械宣传。下面的规则是制片时的起点，不是法律意见；正式上线前请品牌方确认。

## 事实表补充字段

- **全成分（INCI 名称）与关键成分含量**：含量写规格书原文（"含 2% 烟酰胺"），不从成分表顺序反推。
- **容量**（ml / g）、**保质期 / 开封后使用期限**（PAO 标志，如 12M）。
- **适用肤质 / 发质与使用方法**：用量、顺序、频率、注意事项（避开眼周、过敏测试）。
- **功效说法与依据**：测试类型（消费者自评 / 仪器测试 / 皮肤科医生监督）、机构、样本数、时长、结果原文。例如"28 天、32 名受试者、仪器测量，皮肤含水量提升 x%"。
- **法规分类**：日本 化粧品 / 医薬部外品；中国 普通化妆品 / 特殊化妆品（美白、防晒、祛斑等需注册）；美国 cosmetic / OTC drug（防晒、止汗、去屑在美国是 OTC 药品）；欧盟按 1223/2009 化妆品法规。分类决定能说什么。
- **认证**：有机（COSMOS、ECOCERT）、纯素、无动物实验（Leaping Bunny 等）及编号。

## 不能说 / 慎用

- **医疗 / 药效说法**："治疗痘痘""消除皱纹""消炎""生发""医用级""效果媲美肉毒"。改成化妆品范围内的说法，并带依据：
  - "淡化细纹的外观"（en: reduces the appearance of fine lines）而不是"消除皱纹"。
  - "帮助预防因干燥导致的粗糙"而不是"修复皮肤屏障"（后者在多数市场需要更强依据）。
- **日本 薬機法**：化粧品只能在厚生労働省列出的效能范围（56 项）内表达；"美白""シミを防ぐ"只有医薬部外品可以说，而且要用承认的措辞（"メラニンの生成を抑え、シミ・そばかすを防ぐ"）；不说"アンチエイジング""若返り""治る"。"医師推奨"类表达和使用者体验谈（"使ってシミが消えた"）同样受限。
- **中国**：《化妆品监督管理条例》与功效宣称评价规范要求功效宣称有评价依据；美白、祛斑、防晒、防脱等属于特殊化妆品，没有注册证不能宣称。《广告法》禁止医疗用语和极限词。
- **美国**：宣称影响身体结构或功能（"regrows hair""heals acne"）会让商品被视为药品（FDA）；"clinically proven"需要真实的临床研究。
- **欧盟**：化妆品宣称须符合法规 655/2013 的共同标准（合法、真实、有证据、诚实、公平、让消费者知情决策）。"不含 XX"（free from）不能贬低合法成分或暗示法规本来就禁止的东西。"无动物实验"在欧盟是法定前提（化妆品动物实验禁令），单独当卖点可能误导。
- **天然 / 有机 / 纯素 / 低敏 / 皮肤科测试**：都要有认证或测试报告。"hypoallergenic"不能暗示零过敏风险。

## 素材与拍摄风险

- **前后对比照**：只用真实、同光线、同机位、未修图的对比；要写清使用时长与条件。英国 ASA 明确处理过美妆广告里滤镜夸大效果的案例；任何市场都不要在对比照上磨皮、调亮或换肤色。
- **模特**：要有肖像授权，授权范围覆盖电商视频与各个上线市场。不出现未成年人用成人化妆品。
- **医疗暗示的画面**：白大褂、注射器、手术室、显微镜下的"细胞修复"动画都会把商品往药品方向拉，默认不用。
- **质地和颜色**：膏体、粉体的颜色必须与实物一致，调色只修白平衡。色号多的商品，没有实拍的色号不出现。
- **成分可视化**：成分"渗透进皮肤"的 3D 动画暗示药理作用，要有依据，否则只展示成分名和含量。

## 母题来源

- 质地：挤出、拉丝、乳液铺开、粉体压碎、啫喱回弹、泡沫。
- 包装结构：泵头、滴管、磁吸盖、补充装、旋转口红。
- 使用动作：按压、点涂、推开、拍打、喷雾。
- 成分来源（有出处时）：植物、矿物、发酵。只做氛围，不暗示功效。
- 目标顾客：肤质（干、油、敏感）、生活方式（通勤妆、户外、健身后）、年龄段（避免暗示"逆龄"）。

## 常见叙事结构

- **质地巡礼**：包装 → 打开 → 质地 → 上脸 → 收尾。适合以使用感为卖点的商品。
- **一个使用步骤**：早晚护肤流程中的位置，配用量和顺序。
- **成分 → 感受**：关键成分名与含量 → 使用感（"清爽不黏"）→ 有依据的结果。
- **色号陈列**：同一机位、同一光线逐个切换，节拍对重拍。

## 声音

- 录音素材：泵头按压、盖子"咔"一声、玻璃瓶轻碰、喷雾、粉扑拍打、刷子扫过。
- 配乐起点：干净的钢琴与弦乐、温暖的 lo-fi、轻快的流行律动（彩妆）；避免医疗感的冰冷合成音色。
- 质地镜头可以让音乐退后，留出 ASMR 式的细节声，但不要做成需要听声音才能理解的信息。
