# 品类笔记：摩托车周边 / 改装件

这是本 skill 最早实际制片的品类，下面的规则来自真实项目。适用于：シートバッグ、タンクバッグ、サイドバッグ、スマホホルダー、キャリア、ステー、レバー、ミラー、灯具、护具与头盔周边、清洁保养用品等。头盔、灯具、刹车相关部件涉及安全法规，按"安全相关"一节额外处理。

## 事实表补充字段

- **适配车型 / 年份 / 适配条件**：只写资料列出的车型和年份。"多くの車種に対応""universal fit""passt für die meisten Motorräder"这类说法要有资料依据，并把适配条件（管径、取付穴、ステー形状、荷台サイズ）一起写清。资料之间有矛盾就问用户，不自己挑一个。
- **认证**：日本 車検対応 / 保安基準適合 / JIS；欧盟 E-mark（ECE 规则编号）；德国 ABE / StVZO / TÜV 部件证明；美国 DOT / SAE（灯具、头盔 FMVSS 218）。必须有认证编号、证书或规格书原文。
- **性能**：防水（IPX 等级与测试条件）、耐荷重、耐熱、UV カット。只有"防水仕様"几个字的，不要升级成"完全防水"或"IP67"。
- **使用限制**：公道使用不可 / off-road only / nur für den Rennsport、要专业安装、需要另购部件。方向和文案不能与之矛盾：注明公道不可的部件，不能拍成在街上骑行。

## 不能说 / 慎用

- **純正 / OEM / genuine / Originalteil / pièce d'origine / 原厂**：适配品不能说成原厂件，也不能暗示与车厂合作。车型名用文字写，不出现车厂 Logo。
- **安全保障**：头盔、护具、灯具、刹车相关部件，不做"安全保障""protects you in any crash"类承诺；只陈述认证和测试结果。
- **合法性**：在没有对应市场认证时，不说"street legal""StVZO-konform""車検対応"。认证是按市场的：日本的車検対応不等于欧盟或美国合法。

## 素材与拍摄风险

- **车厂 Logo、徽标、车名贴纸**：裁掉、虚化或压暗到不可辨认（见 [视觉手法词汇](../visual-vocabulary.md) 的"实装场景"）。
- **车牌**：完全遮挡。遮挡层随镜头一起移动和缩放，每一帧都要盖住。
- **骑手**：有使用许可才出现可辨认的脸，否则只拍手、背影或戴头盔的样子。骑行姿态和装备要合理：戴头盔，不做危险动作。
- **车辆**：车辆是别人的设计，不做画面主角。镜头聚焦商品，车身可降低饱和度和亮度。
- **别家商品**（头盔、手套、包）的商标同样遮挡。

## 母题来源

- 结构：扣具、拉链、可调节关节、反光条、切削面、阳极氧化的颜色。
- 使用动作：装上、卡住、拉紧、展开、收纳、拧紧。
- 安装位置与车体的关系：シート上、タンク上、ハンドル周り、リア、ヘルメット。
- 骑行场景：雨天、夜间、长途ツーリング、拥堵通勤、越野、山路。
- 目标骑手：通勤族、长途ツーリング、オフロード、カスタム好き、女性骑手、新手。

痛点的例子（必须真实存在于目标骑手身上）：雨天行李湿、导航看不清、手机掉、停车后担心被偷、改装后不好看。

## 常见叙事结构

- **安装三步走**："装起来简单"是主要卖点时用。步骤与说明书一致，漏掉需要工具的步骤就是虚假。
- **一次ツーリング**（出发 → 路上 → 到达）：适合收纳、导航、通讯类。
- **装着前后**：适合外观改装件。只和自己车的未改装状态比，机位要一致。
- **痛点 → 解决**：防雨、防盗、防掉落类。

## 声音

- 录音素材优先：搭扣扣合、拉链、魔术贴撕开、织带拉紧、金属件拧紧、手机卡进支架、轮胎压过路面、雨声。
- 引擎声、排气声：可辨认的特定车型声音可能来自别人的录音作品，按素材许可使用。商品与发动机无关时，不要为了"有摩托感"硬加。
- 配乐起点（只是起点，按方向文件的声音轴再定）：

| 骑手 / 商品 | 配乐方向 |
|---|---|
| 越野、运动骑行装备、护具 | 失真吉他、有冲击力的鼓，140–175 BPM，build–drop |
| カスタム、复古车、街头通勤 | Rhodes、爵士和弦、lo-fi 鼓、黑胶底噪 |
| 长途ツーリング、露营、新手 | 指弹木吉他、毛毡钢琴、鼓刷、环境录音 |
| 都市夜骑、骑行服饰 | Deep house 118–124 BPM，或 Techno（夜间、灯具、反光类） |
| 精密加工件、碳纤维 | 稀疏钢琴、次低频、精确的点击声 |
