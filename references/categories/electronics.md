# 品类笔记：3C 电子 / 配件

适用于：充电器、充电宝、数据线、无线充、扩展坞、耳机、音箱、手机壳与支架、键鼠、小型智能设备等。带加热、电机或电池的个护设备（美容仪、电动牙刷）同时读 [美妆 / 个护](beauty.md)。

## 事实表补充字段

- **兼容设备 / 接口 / 协议**：USB-C PD（版本与档位）、QC、Qi / Qi2、MagSafe、蓝牙版本与编解码。兼容清单要有出处（规格书、厂商测试表），**"兼容所有设备"不是事实**。
- **输入 / 输出 / 容量**：W、V/A、mAh、Wh。充电宝写额定容量还是电芯容量，要和规格书一致。多口同时输出时的功率分配要单独写，不能只写最大单口功率。
- **速度说法与测试条件**："30 分钟充到 50%"必须带测试设备、起始电量、温度等条件，画面上至少带"测试设备"或注释。
- **认证与编号**：日本 PSE（电気用品安全法）、技適（無線機器，电波法）；欧盟 CE（自我声明，不是认证机构颁发）、英国 UKCA；美国 FCC ID；第三方 UL / ETL；Qi2 Certified（WPC 认证）；MFi（Made for iPhone，Apple 授权）。
- **防护与耐用**：IP 等级（IEC 60529，写清 IPX4 / IP67 的含义和测试条件）、跌落测试高度与次数。
- **电池与运输**：电芯类型、Wh 数（航空携带规定通常按 Wh 判断），不要替航空公司做承诺。

## 不能说 / 慎用

- **"military grade" / 军工级 / ミリタリーグレード**：除非有 MIL-STD-810 的具体测试报告（方法号与项目），否则不用；即使有，也写"按 MIL-STD-810H 516.8 跌落测试"而不是"军工级"。
- **绝对安全**："never overheats""explosion-proof""绝不发热"。改成具体保护机制（过温保护、过流保护）和认证。
- **第三方商标**：Apple、iPhone、MagSafe、Samsung、Galaxy 等。"兼容 iPhone 15"可以作为兼容性事实写出（文字，不用对方 Logo）；"Made for iPhone"和 MFi 徽标只有获得 MFi 授权才能用；"MagSafe 兼容"与"Made for MagSafe"不是一回事。
- **CE 当卖点**：CE 是在欧盟销售的法定前提，在德国把法定要求当成特别优点宣传，可能构成误导（Werbung mit Selbstverständlichkeiten）。CE / UKCA / PSE 可以出现在规格画面，不做成主打卖点。
- **"世界最小 / 最轻 / 最快"**：需要有时间、范围和方法的比较依据，Amazon 视频里通常直接避开。

## 素材与拍摄风险

- **屏幕内容**：手机、电脑屏幕上不出现第三方 App 的界面和 Logo、真实通知、真实联系人、地图上的真实住址。用中性壁纸或自制界面。
- **被兼容的设备**：出镜的手机、电脑是别人的商品。优先用无 Logo 的角度，或压暗、虚化；不要让别家商品成为主角。
- **LED / 指示灯**：真实照片里的灯效可以用光效层增强亮度，但颜色和位置要与实物一致，不要画出实物没有的灯。
- **线材与接口**：接口特写最容易暴露"照片其实是别的型号"，型号、接口数量、印字要与本商品一致。
- **爆炸图 / 内部结构**：只用厂商提供的结构图或拆解照片；不要凭想象画内部电路和电芯。

## 母题来源

- 结构：接口、折叠插脚、磁吸环、散热鳍片、编织线、指示灯。
- 物理现象（有数据时）：功率数字、电量百分比上升、磁吸"咔"一下的对齐、线缆弯折次数。
- 使用动作：插上、吸附、折叠、收进口袋、一根线同时给多台设备充电。
- 使用场景：出差、桌面整理、通勤、户外、游戏。
- 目标顾客：多设备的科技爱好者、商务出差、学生、家庭、游戏玩家。

## 常见叙事结构

- **一个桌面 / 一个包**：杂乱 → 一件商品解决（只和自己的使用前状态比，不和别家商品比）。
- **规格巡礼**：接口逐个点亮，标注功率与协议。适合多口充电器、扩展坞。
- **一天的电量**：早 → 午 → 晚，电量条随时间变化。数字必须来自规格书或带条件的测试。
- **尺寸对比**：和日常物件（硬币、名片）对比大小。对比物要真实拍摄或按真实尺寸缩放。

## 声音

- 录音素材：Type-C 插入、磁吸吸附、按键、折叠插脚的"咔嗒"、线材甩动。
- 合成音适合本品类：数据感的 click、上升 sweep、确认 ding；不要在没有提示音的商品上加假的开机音。
- 配乐起点：模块合成器琶音、glitch 打击乐、极简钢琴、乐观的大调（湾区科技感）；高价位商品用稀疏、干净的电子乐。

## 推导示例

| 商品有什么（事实表里有） | 可以长成什么 |
|---|---|
| 折叠插脚 | 插脚收起的一瞬间切到口袋特写，配机械"咔嗒"声 |
| 3 口同时输出，各口功率有表 | 三条光线依次从接口流向三台设备，标注各自功率 |
| Qi2 磁吸对位 | 手机靠近时磁吸环亮起一圈，吸附瞬间配低沉的 thump |
| 编织线、弯折测试数据 | 线材在微距下缓慢弯折，计数器滚到测试次数 |
